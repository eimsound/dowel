# 账户、OIDC 与权限

本页说明 Dowel 的单公司账户模型、邀请与密码重置流程、通用 OIDC 外部登录配置、组与项目角色计算规则、个人设置以及审计与动态记录。

## 账户与登录 {#accounts-and-login}

- **单公司实例模型**：一个 Dowel 部署只服务一家公司。实例内所有已登录用户均可见所有**组**的名称与成员列表，但**项目**仅对拥有权限的人可见；无权访问的项目在 HTTP 接口（列表、搜索、直接链接）中一律返回不存在（404），在 WebSocket 中则对无权或不存在的项目以关闭码 `4401` 断开连接（已连接后用户被停用或权限被收回时以关闭码 `4403` 断开）。
- **用户名规则**：登录凭据为**用户名 + 密码**或外部 OIDC 身份。用户名由小写字母、数字和 `-` 组成，长度 1–39 位，全实例唯一（可在个人设置中修改）。邮箱仅为个人资料中的可选字段，不校验唯一性，也不用于登录、找回密码或自动关联外部账户。
- **仅限邀请注册**：不开放自由注册。实例管理员可在管理后台直接创建用户（若填写了初始密码，则该用户首次登录时必须先修改密码；留空时仅允许外部 OIDC 登录），或生成一次性邀请链接（`/invite/<令牌>`，默认 7 天有效），受邀人点击后自主设定用户名与密码，也可预先绑定要加入的组。
- **重置密码**：实例管理员可在用户列表点击“重置密码”为用户设置或自动生成一次性临时密码；确认重置后，该用户所有现有会话立即失效、在线协作 WebSocket 连接会立即断开（关闭码 `4403`），且对方下次登录时必须修改密码。
- **重置链接端点兼容性**：后端保留自助一次性重置链接端点（`POST /api/admin/users/:id/reset-link` 与 `/reset/<令牌>`，24 小时有效）；用户通过重置链接完成改密后同样会吊销现有会话并清除强制改密标记。
- **停用用户**：停用会立即销毁该用户的全部会话，并主动断开其在所有协作房间里的 WebSocket 连接（关闭码 4403）。系统保留至少一名活跃实例管理员，最后一名实例管理员无法被停用或降级。

## 配置 OIDC 登录 {#oidc}

Dowel 支持标准 OpenID Connect（授权码模式 + PKCE S256），由实例管理员在“管理后台 → 实例设置 / 登录方式”配置，包含 Google、GitLab 预设模板以及任意通用 OIDC 提供方。

### 配置前提 {#oidc-prerequisites}

- 设置环境变量 `DOWEL_SECRET`（至少 16 个字符）：OIDC 的 `clientSecret` 使用该密钥加密存储，保存后管理列表不再返回明文。若修改了 `DOWEL_SECRET`，旧密文无法解密，需重新填写 `clientSecret`。
- 建议设置 `DOWEL_PUBLIC_URL`（如 `https://dowel.example.com`）：回调地址与站外链接依赖它推导；在反向代理后部署时同时设置 `DOWEL_TRUST_PROXY=1`。
- 回调地址格式固定为：

```text
{DOWEL_PUBLIC_URL}/api/auth/oidc/{slug}/callback
```

其中 `{slug}` 为添加提供方时填写的标识（如 `google`、`gitlab`、`corp-sso`）。

### Google 与 GitLab 常见步骤 {#oidc-providers}

=== "Google"

    1. 在 Google Cloud Console 创建 OAuth 2.0 Client（应用类型为 Web application）。
    2. 将 Authorized redirect URI 设为 `https://你的域名/api/auth/oidc/google/callback`。
    3. 在“管理后台”或调用 `/api/admin/oidc` 添加提供方：
       - `slug`：`google`
       - `issuer`：`https://accounts.google.com`
       - `scopes`：`openid profile email`

=== "GitLab"

    1. 在 GitLab（`gitlab.com` 或自建实例）的 Admin → Applications 中创建 OAuth 应用。
    2. 将 Redirect URI 设为 `https://你的域名/api/auth/oidc/gitlab/callback`，勾选 `openid`、`profile`、`email`。
    3. 添加提供方时将 `issuer` 设为 `https://gitlab.com`（自建实例填写 `https://gitlab.example.com`）。
    4. 默认仅允许已受邀的用户登录关联；若允许未受邀人员首次用 OIDC 自动开户，需显式将提供方的 `autoProvision` 设为 `true`。

### 个人身份关联与密码登录开关 {#oidc-linking}

- **身份关联**：已登录用户可在 `/account/identities` 绑定或解绑外部 OIDC 身份（绑定走 `GET /api/auth/oidc/{slug}/start?mode=link`）。系统按 `(provider_id, subject)` 精确识别用户，绝不按邮箱自动合并用户。若解绑后用户既没有密码也没有其他登录方式，服务端将拒绝解绑（422）。
- **关闭密码登录**：仅当实例至少存在一个已启用的 OIDC 提供方时，才允许在管理后台关闭密码登录。若因 OIDC 提供方异常导致无法登录，可将环境变量 `DOWEL_ALLOW_PASSWORD_LOGIN=1` 注入服务端作为应急恢复入口。

## 组、项目角色与授权 {#groups-and-grants}

### 组与项目创建 {#groups}

- 组是一层扁平结构，不嵌套，一个用户可以属于多个组。
- 默认所有用户均可创建新组，创建者成为该组的**组管理员**（实例管理员可在管理后台限制为仅实例管理员可建组）。组的“新建项目”权限默认为全体组成员，组管理员可收紧为仅组管理员。
- 组内仍存在项目时不能删除该组。
- 在项目“成员与授权”或项目设置中可将项目转移到另一个组（需要同时拥有源组和目标组的组管理员权限，或由实例管理员操作）。项目转移后 URL 更新为新组地址，旧地址与旧路径请求会自动重定向，但原组范围的授权与执行者不会自动带入新组。

### 项目角色与生效计算 {#project-roles}

**项目角色**只控制模型（编辑画布、导入、发布版本、查看脚本与环境），与目标库执行权限分离。共有三级：

- **查看者（Viewer）**：只读查看模型、版本链、迁移脚本、环境与动态；
- **编辑者（Editor）**：可编辑工作副本、导入结构、发布版本、手动检查漂移，以及在未收紧的环境下提交执行申请或执行（默认非生产环境允许项目编辑者执行）；
- **项目管理员（Admin）**：可管理项目成员授权、修改项目设置、配置环境变量/连接串、删除项目及配置项目级执行策略。

一个用户对某个项目的**最终生效角色**取以下来源中的最高级别：

1. **实例管理员**：对所有组与所有项目自动拥有最高权限；
2. **所属组的组管理员**：对本组全部项目拥有项目管理员权限；
3. **项目/组的默认权限**：组成员自动获得项目的“默认权限”（未单设时继承所属组的默认权限）；
4. **显式授权（Grant）**：针对该用户或其所在组，在“单个项目”“组的全部项目”或“整个实例”范围授予的角色。

角色或授权调整后**即时生效**：正在实时协作的客户端会自动切换为只读或被断开连接（4403），无需刷新页面。系统保证每个项目至少有一名项目管理员、每个组至少有一名组管理员（实例管理员不计入该保底限制）。

### 执行者授权 {#executors}

除上述模型角色外，可将用户或组额外授予**执行者（Executor）**角色（范围可设为单个环境、单个项目、整组项目或全实例）。执行者授权会自动赋予只读查看对应项目的权限，并在任意执行策略档位下拥有执行特权操作的资格。关于生产环境设为“仅限执行者”时只能由实例管理员授予执行者的规则，见 [执行策略与执行者](execution-policy.md)。

### 删除项目 {#delete-project}

项目管理员可在项目设置中删除项目（需原样输入项目标识 `slug` 确认）。删除操作在一个事务内清理平台侧的项目、模型房间、版本链、环境配置、授权、执行策略与 CI 令牌，断开该项目的在线协作连接并关闭相关影子库连接池。**不会修改目标数据库中的结构或 `dowel` 迁移历史**，审计记录亦完整保留；若后续需要恢复，可通过 [接手现有项目](takeover.md) 重建平台项目。

## 个人设置、命令面板与审计 {#account-and-audit}

- **个人设置（`/account`）**：支持修改用户名、显示名与邮箱（`/account`），修改或首次设置密码（`/account/password`），管理已关联的 OIDC 身份（`/account/identities`），查看并注销活跃会话（`/account/sessions`），以及切换中英文界面语言偏好（`/account/preferences`）。
- **命令面板**：按 `⌘K`（或 `Ctrl+K`）可跨组和项目快速跳转、打开新建项目或新建组入口、切换界面操作。
- **项目动态与实例审计**：
  - 在项目内打开“动态”页（`/project/:owner/:project/activity`），可查看模型导入、发布、恢复、环境变更、成员授权与执行申请等活动记录；
  - 实例管理员可在“管理后台 → 审计日志”（`/admin/audit`）按操作类型前缀、操作者、目标对象及时间范围游标检索全实例安全审计日志。
